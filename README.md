# YootsClaw.ai

AI-agent platform. Any channel. Any API.

## Quick Start
```bash
npm install -g yootsclaw
yootsclaw init
```

## What is YootsClaw?

Self-hosted AI-agent platform. One CLI command — full system.
AI agents controlled via Telegram, connected to any external API.

- Telegram + WhatsApp + Discord + Slack (plugin system)
- Universal API Adapter: any REST API via YAML in 5 min
- Skills Marketplace: free / premium / community
- Telegram Mini App Builder: 10 templates + AI generation
- Tool Policy: allow/deny per agent
- MIT core, commercial premium skills
